Endpoint siap menerima callback

Order Itemku langsung masuk Telegram.

Serverless notifier untuk menerima Order Callback Itemku dan meneruskan notifikasi ke Telegram. Tidak memakai polling browser, sehingga jalurnya langsung dari callback Itemku ke server lalu Telegram.

Webhook URL

Masukkan URL berikut sebagai URL Order Callback di Itemku.

Metode: POST · Content-Type: application/json

Test Telegram

Gunakan setelah Environment Variables di Vercel sudah diisi.

Environment Variables

TELEGRAM_BOT_TOKENToken bot Telegram
TELEGRAM_CHAT_IDID chat/grup tujuan
ITEMKU_SHOP_IDShop ID untuk validasi header
ITEMKU_API_KEYAPI Key Itemku
ITEMKU_API_SECRETSecret Key Itemku
VERIFY_ITEMKUfalse tercepat / true verifikasi API

Deploy di Vercel

  1. Upload folder/ZIP ini ke GitHub, atau import project ke Vercel.
  2. Di Settings → Environment Variables, isi semua variable.
  3. Deploy/redeploy project.
  4. Buka website ini dan tekan Kirim Test.
  5. Salin URL /api/webhook ke konfigurasi callback Itemku.

Jika Itemku meminta verifikasi DNS TXT, gunakan domain yang dapat Anda kelola DNS-nya (custom domain lebih praktis daripada domain bawaan Vercel).

Keamanan & retry

  • Token Telegram dan Secret Itemku hanya berada di environment server.
  • Header X-itemku dapat divalidasi terhadap ITEMKU_SHOP_ID.
  • Callback diproses berdasarkan order_id agar retry tidak membuat notifikasi dobel pada instance yang sama.
  • Untuk skala tinggi/multi-instance, gunakan Redis/KV sebagai penyimpanan idempotency permanen.
